# 🔐 Cipher Chase

An interactive browser-based cryptography challenge game that teaches core cybersecurity and encryption concepts through hands-on puzzles.

Built using pure HTML, CSS, and JavaScript to demonstrate logic-first engineering without frameworks or libraries.

---

## Overview

Cipher Chase turns cryptography into an interactive experience.

Instead of reading theory, players actively solve encryption challenges including classical ciphers, substitution tables, and public-key math.

The goal is simple:
Think like a cryptographer. Solve like an attacker.

---

## Features

### Level-Based Progression
- Level 1 — Caesar Cipher (Decrypt)
- Level 2 — Caesar Cipher (Encrypt)
- Level 3 — 6→4 bit S-Box substitution
- Level 4 — RSA encryption math
- Final score + completion screen

### Game Mechanics
- Randomized questions each playthrough
- Attempt-based scoring system
- Hints for learning support
- Reset functionality
- Floating live scoreboard

### Visual Experience
- Matrix-style animated background
- Falling binary particles
- Terminal / hacker-themed UI
- Responsive layout
- Canvas animations

## Concepts Covered

This project reinforces real cybersecurity knowledge:

- Classical cryptography
- Substitution and transformation logic
- Bit-level operations
- S-Boxes (block cipher components)

- RSA encryption fundamentals
- Input validation and game state management

If you can solve every level manually, you understand the foundations behind basic modern encryption systems.
